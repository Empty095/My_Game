Это мой проект игры, для практики работы с ооп.

Данная игра является пошаговым файтингом, в которой есть возможности играть с другом на одном устройстве, так и игра против бота.
Есть вещи которые влияют на характеристики игрока и сущностей, а хранятся они в инвентаре который имеет также свой функционал.

Игровые механики: атака, защита, ульта;
Сущности которые присутствуют или будут добавлены: игрок, тень, жнец, бог;
Предметы: Sword, Reaper's Scythe, Iron Set, Apple, Totem God.

Для запуска использовать файл: script.py

Дополнение: данный проект будет обновляться, по этому, это не финальное описание и оно может меняться.
